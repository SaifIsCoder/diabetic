# 11 - Master Bug Tracker

This master bug tracker consolidates all confirmed defects, security vulnerabilities, compliance failures, architectural flaws, performance bottlenecks, and accessibility blockers identified across the 10 specialist audits of the Diabetic Retinopathy Detection Application, along with their remediation status.

---

## 1. Consolidated Master Defect Matrix

| ID | Module | Issue | Severity | Status | Recommended Fix / Remediation Applied |
| :--- | :--- | :--- | :---: | :---: | :--- |
| **SEC-01** | `supabase/migrations/004_security_remediation_sprint1.sql` | **BOLA in Clinician Grant Claim**: RLS policy allowed any authenticated clinician to claim any active patient grant without supplying the authorization code. | **Critical** | **Verified Remediated (Sprint 1)** | Dropped permissive UPDATE policy; created atomic `claim_clinician_access(p_code)` SECURITY DEFINER RPC with row-level lock and single-use consumption. |
| **SEC-02** | `app.py:api_predict` | **Authentication Bypass / Fail-Open**: If `SUPABASE_JWT_SECRET` was unset, backend allowed unauthenticated inference; mobile client transmitted no JWT headers. | **Critical** | **Verified Remediated (Sprint 1)** | Enforced fail-closed JWT verification; missing/invalid/expired Bearer JWT returns 401; missing secret in production raises fatal error. |
| **ARCH-01** | `app.py`, `supabase/migrations/004_...` | **Client-Side Scan Record Persistence**: Mobile client directly wrote AI diagnosis grades to `scans` table, allowing malicious tampering, forged grades, and dropped records. | **Critical** | **Verified Remediated (Sprint 1)** | Added server-side HMAC-SHA256 scan receipts in `/api/predict` and verification endpoint `/api/scans/verify-receipt`; enforced DB trigger immutability. |
| **QA-01** | `mobile/app/(tabs)/clinicians.tsx` | **Clinician Review Workflow Blocker**: Clinician review inspection modal displays scan grades and metrics but completely omits retinal image preview. | **Critical** | Confirmed (Open - Sprint 2) | Fetch and render fundus image using signed Supabase storage URL with zoom/pan capabilities inside the clinician review modal. |
| **PR-01** | `Dockerfile` | **Missing Validator File**: `Dockerfile` omits `gemini_validator.py`, causing immediate container crash on startup when imported by `app.py`. | **Critical** | Confirmed (Open - Sprint 2) | Add `COPY gemini_validator.py .` to `Dockerfile` build instructions. |
| **PR-07** | `gunicorn.conf.py` | **Gunicorn Thread Starvation & Crashloop**: Micro-pool (4 threads total) starves during heavy concurrent inference or slow Gemini calls, failing health checks. | **Critical** | Confirmed (Open - Sprint 2) | Increase workers/threads or deploy Celery/Redis queue for async model inference decoupled from WSGI request threads. |
| **ML-01** | `85.ipynb` | **Severe Training Data Leakage**: Data augmentation performed before dataset split; augmented siblings cross train/val/test splits, invalidating reported 87.7% accuracy / 0.958 kappa. | **Critical** | Confirmed (Open - Sprint 2) | Re-split dataset strictly at the patient/original image level before applying offline or online data augmentation. |
| **PRIV-01** | `gemini_validator.py`, `app.py` | **Unprotected PHI Transmission to Consumer AI API**: Retinal scans sent to Google Gemini Flash API without Business Associate Agreement (BAA) or enterprise privacy terms. | **High** | **Verified Remediated (Sprint 1)** | Documented Vertex AI BAA compliance path; added input byte sanitization; enforced storage deletion policy for GDPR right to erasure. |
| **SEC-03** | `app.py` | **CORS Wildcard Reflection with Credentials**: Backend reflected `request.headers.get("Origin")` with `Access-Control-Allow-Credentials: true`. | **High** | **Verified Remediated (Sprint 1)** | Replaced wildcard reflection with explicit allowed origin whitelist (`ALLOWED_ORIGINS`); rejects unlisted origins. |
| **SEC-04** | `supabase/migrations/004_security_remediation_sprint1.sql` | **Unverified Clinicians Access Medical Records**: Clinicians with `is_verified = FALSE` could view delegated patient scans and download raw retinal images. | **High** | **Verified Remediated (Sprint 1)** | Hardened RLS policies on `public.scans` and `storage.objects` to strictly require `clinician_profiles.is_verified = TRUE`. |
| **SEC-05** | `mobile/constants/api.ts` | **Insecure Public Localtunnel Transport**: Development routes sensitive medical images over public `loca.lt` proxy without TLS certificate pinning or access controls. | **High** | Confirmed (Open - Sprint 2) | Prohibit third-party HTTP tunnels in staging/production; deploy backend behind TLS reverse proxy (Cloud Run / AWS ALB / NGINX). |
| **SEC-06** | `supabase/migrations/004_security_remediation_sprint1.sql` | **Unconstrained Scan Record Mutation**: Scans table allowed users to mutate existing historical diagnostic records. | **High** | **Verified Remediated (Sprint 1)** | Created `protect_scan_immutability()` database trigger locking `grade`, `confidence`, `image_url`, `created_at`, `patient_id`; allowed only notes updates. |
| **SEC-07** | `app.py` | **Absence of API Rate Limiting**: Compute-intensive inference and paid Gemini triage endpoints lacked rate limiting, risking DoS and cloud bill exhaustion. | **High** | **Verified Remediated (Sprint 1)** | Integrated `Flask-Limiter` with tiered limits (10/min on `/api/predict`, 60/min on `/api/health`, 30/min on `/api/scans/verify`). |
| **SEC-08** | `supabase/migrations/004_security_remediation_sprint1.sql` | **Weak Pseudo-Random Grant Code**: 6-character alphanumeric grant code generated client-side with `Math.random()`, vulnerable to brute force and collision. | **High** | **Verified Remediated (Sprint 1)** | Implemented `generate_patient_grant_code()` database RPC using `gen_random_bytes(6)` over a 32-character CSPRNG keyspace. |
| **ML-02** | `app.py`, `retfound_model.keras` | **Model Architecture Identity Mismatch**: Model is advertised as RETFound (Vision Transformer) but is actually standard DenseNet-121. | **High** | Confirmed (Open - Sprint 2) | Correct system documentation, UI labels, and model references to accurately reflect DenseNet-121 architecture, or deploy authentic RETFound weights. |
| **ML-03** | `app.py:predict_grade` | **Omitted Input Normalization**: Model receives raw [0, 255] RGB pixel values rather than ImageNet normalization required by DenseNet-121. | **High** | Confirmed (Open - Sprint 2) | Insert proper normalization `tf.keras.applications.densenet.preprocess_input` or standard ImageNet z-score scaling into inference pipeline. |
| **ML-04** | `app.py`, `gemini_validator.py` | **Failure Modes on Out-of-Distribution Inputs**: Blank, gray, checkerboard, or noise images predict Grade 1 (Mild DR) with >93% confidence when validator is bypassed. | **High** | Confirmed (Open - Sprint 2) | Implement input entropy and pixel variance checks in `validate_image_bytes` to reject non-informative synthetic inputs before model inference. |
| **ARCH-06** | `app.py`, `mobile/app/(tabs)/index.tsx` | **Absence of Grad-CAM / Visual Explainability**: System returns only raw numbers without lesion localization (microaneurysms, hemorrhages, exudates). | **High** | Confirmed (Open - Sprint 2) | Implement Grad-CAM heatmap generation on last convolutional layer of DenseNet-121 and render heatmap overlay on mobile UI. |
| **UX-01** | `mobile/app/(tabs)/index.tsx` | **Diagnostic Overclaiming**: UI labels automated AI output as "Diagnostic Assessment" and "Diagnosis" rather than an investigational screening aid. | **High** | Confirmed (Open - Sprint 2) | Revise all UI copy, headers, and modal text to "Automated DR Screening Assessment" and emphasize mandatory clinical confirmation. |
| **UX-02** | `mobile/app/(tabs)/index.tsx` | **Off-Screen Medical Disclaimer**: High-severity screening results place the clinical disclaimer below the fold, hidden unless scrolled. | **High** | Confirmed (Open - Sprint 2) | Anchor clinical disclaimer immediately beneath the result card and trigger high-priority alert modal for Grade 3/4 detections. |
| **A11Y-01** | `mobile/constants/Colors.ts`, `mobile/app/(tabs)/index.tsx` | **Severe Color Contrast Failures (WCAG 1.4.3)**: Dark mode primary buttons (#FFFFFF on #20B2AA) fail at 2.62:1; History badges fail at 2.39:1. | **High** | Confirmed (Open - Sprint 2) | Adjust color tokens in `Colors.ts` to achieve minimum 4.5:1 contrast ratio against light and dark background surfaces. |
| **A11Y-02** | `mobile/app/(tabs)/index.tsx` | **Silent AI Prediction Delivery (WCAG 4.1.3)**: Screen reader users receive no audio notification when AI assessment completes. | **High** | Confirmed (Open - Sprint 2) | Add `accessibilityLiveRegion="assertive"` and trigger `AccessibilityInfo.announceForAccessibility` upon inference completion. |
| **PR-04** | `docker-compose.yml` | **Missing Gemini Environment Variables**: `docker-compose.yml` omits `GEMINI_API_KEY`, causing prediction failure in dockerized environments. | **High** | Confirmed (Open - Sprint 2) | Add `GEMINI_API_KEY` and validation configuration flags to `docker-compose.yml` environment blocks. |
| **PR-08** | `.env` | **Live Secret Committed in Root Directory**: Google Gemini API key was present in repository root `.env` file. | **High** | **Verified Remediated (Sprint 1)** | Purged plaintext key from `.env`; added rotation notice and Secret Manager guidance in `.env.example`. |
| **PR-14** | Application-wide | **Zero Error Monitoring / APM**: No error tracking (e.g. Sentry) or APM exists, leaving production crashes completely unobserved. | **High** | Confirmed (Open - Sprint 2) | Integrate Sentry SDK in both Flask backend (`sentry-sdk[flask]`) and mobile client (`@sentry/react-native`). |
| **PERF-01** | `app.py`, `retfound_model.tflite` | **Unused 7.31x Faster TFLite Runtime**: App runs heavy Keras model (520ms) while identical TFLite model (71ms, 27.6MB) sits unused in repository. | **Medium** | Confirmed (Open - Sprint 2) | Switch backend inference runtime to `tflite_runtime.interpreter` or `tf.lite.Interpreter`, reducing latency by 86.3%. |
| **PERF-02** | `app.py`, `gemini_validator.py` | **257ms Double-Decode & LANCZOS Waste**: Image is compressed to JPEG 95 by validator then re-decoded and scaled with LANCZOS filter. | **Medium** | Confirmed (Open - Sprint 2) | Pass decoded PIL Image directly from validation gate to inference preprocessor and replace LANCZOS with BILINEAR resampling. |
| **PERF-03** | `app.py` | **Concurrency Contention & 2.58 GB RAM Spike**: Concurrency crashes 2GB cloud containers due to unthrottled TensorFlow CPU thread spawning. | **Medium** | Confirmed (Open - Sprint 2) | Set `tf.config.threading.set_intra_op_parallelism_threads(2)` and deploy Celery worker pool with pre-fork concurrency limits. |
| **PERF-05** | `mobile/app/(tabs)/index.tsx` | **Base64 JSON WAN Ingestion**: Mobile client transmits multi-megabyte images as base64 strings (+33% network overhead and 130x decode penalty). | **Medium** | Confirmed (Open - Sprint 2) | Update mobile client to upload raw binary multipart/form-data directly to API endpoint. |
| **PRIV-02** | `supabase/migrations/004_security_remediation_sprint1.sql` | **Missing Storage Purge Policy**: Storage bucket lacked DELETE RLS policy, preventing patients from exercising their Right to Erasure (GDPR Art. 17). | **Medium** | **Verified Remediated (Sprint 1)** | Added `storage.objects` DELETE policy allowing owners to delete their own uploaded retinal scans. |
| **PRIV-03** | `mobile/app/(tabs)/profile.tsx` | **Simulated Account Deletion**: "Delete Account" button in mobile profile is a UI stub that does not delete Supabase auth or clinical scan records. | **Medium** | Confirmed (Open - Sprint 2) | Implement Supabase Database RPC function that cascades deletion across `auth.users`, `profiles`, `scans`, and storage bucket. |
| **PRIV-04** | `mobile/app/(tabs)/history.tsx` | **Unencrypted Local PDF & Image Caching**: Exported clinical reports and downloaded scans persist indefinitely in device unencrypted cache. | **Medium** | Confirmed (Open - Sprint 2) | Implement automated cache purging using `expo-file-system` lifecycle hooks on logout and application backgrounding. |
| **A11Y-03** | `mobile/app/(tabs)/index.tsx`, `clinicians.tsx` | **Sub-48dp Touch Targets (WCAG 2.5.8)**: Eye toggles (26dp), replace pill (28dp), filter tabs (26dp), and close buttons (22dp) violate minimum touch target standards. | **Medium** | Confirmed (Open - Sprint 2) | Increase minimum button dimensions to 48x48dp or apply `hitSlop={{ top: 12, bottom: 12, left: 12, right: 12 }}`. |
| **A11Y-04** | `mobile/app/(tabs)/index.tsx` | **Retinal Image Aspect Ratio Cropping**: 1:1 square aspect ratio with `resizeMode="cover"` crops optic disc and macula on tablet displays. | **Medium** | Confirmed (Open - Sprint 2) | Change image container to maintain native aspect ratio with `resizeMode="contain"` and enable pinch-to-zoom inspection. |
| **UX-03** | `mobile/app/(tabs)/index.tsx` | **Cumulative Probability Logit Confusion**: Raw ordinal threshold logits (Grade >= 0..4) confuse lay patients without clinical guidance. | **Medium** | Confirmed (Open - Sprint 2) | Group ordinal bars into a progressive disease progression gauge with layman risk labels and tooltips. |
| **ARCH-07** | `mobile/app/(tabs)/two.tsx`, `modal.tsx` | **Orphaned Boilerplate & Incomplete Screens**: Template screen `two.tsx` and unfinished `modal.tsx` remain in production navigation tree. | **Low** | Confirmed (Open - Sprint 2) | Delete `two.tsx` and wire `modal.tsx` to clinical screening guidelines or remove from router layout. |
| **QA-02** | `app.py:predict_html` | **Internal Object Representation Leakage**: Web portal template renders `<PIL.JpegImagePlugin...>` string in browser response upon error. | **Low** | Confirmed (Open - Sprint 2) | Sanitize web portal response to return user-friendly error messages instead of raw Python object strings. |
| **A11Y-05** | `mobile/app/(auth)/register.tsx` | **Keyboard Navigation Skips Form Fields**: Focus jump chain bypasses required Specialty chips during clinician registration. | **Low** | Confirmed (Open - Sprint 2) | Implement sequential `onSubmitEditing` and `returnKeyType="next"` ref chaining across all registration inputs. |
